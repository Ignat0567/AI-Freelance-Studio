# AI Freelance Studio — описание для презентации

**Что это.** Локальное десктоп-приложение: оператор вводит заказ на сайте обычным языком, Studio проводит бриф и дизайн, пишет проект, прогоняет QA и отдаёт папку, которую можно открыть без автора.

**Кому.** Фрилансеру или маленькой студии, которой нужен проверяемый сайт или небольшое веб-приложение за один прогон, а не чат с моделью.

**Что умеет MVP.**

- Два продукта: **Website** (один самодостаточный `index.html`) и **Small web application** (Vite/React). Telegram-бот — позже.
- Цепочка: заказ → уточнение → бриф → превью Елены → live-сборка → гейты QA → папка сдачи.
- Елена задаёт композицию страницы под **тему этого заказа** (overlay: имя, навигация, CTA, заголовок на атмосфере мира клиента). Карточка — только если заказ и есть карточка. WebGL — только если бриф про cinematic/3D/живую сцену.
- Код пишет выбранный worker: подписка Grok, локальная Ollama, Claude Code, OpenCode или OpenRouter.
- Сдача: `generated_projects/…` с `README.md`, `delivery_report.md`, `delivery_screenshot.png`. Страница открывается в браузере без сборки.

**Доказанные живые прогоны (из окна Studio).**

| Заказ | Тип | Результат |
|---|---|---|
| Alethia Carbon Intelligence | cinematic website | succeeded, WebGL ~60 fps |
| Harbour Bakery | website, другая тема | succeeded, ~6 мин, 1 ремонт |
| Tip Splitter | small web app | succeeded (bench/UI) |

**Чего это не делает.** Не маркетплейс, не видео, не презентации клиента, не облачный SaaS. Не судит «красоту» отдельным гейтом: гейт меряет файл, HTTP 200, ошибки консоли, overflow, fps/draw calls если есть canvas.

**Установка.** Windows-installer **не требует Python** для окна приложения. Живой заказ всё равно нуждается в Docker Desktop (QA) и Grok CLI (`grok login`). Подробности: `docs/MVP-INSTALL.md`.
