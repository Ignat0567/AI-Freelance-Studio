## Кнопка Start live build не нажимается

Она выключена не просто так: чеклист над ней всегда называет причину и лекарство.
Исправьте названное и нажмите **Refresh readiness** — чеклист не перепроверяет
окружение сам.

| Что написано в чеклисте | Что сделать |
|---|---|
| Claude Code CLI | Выполнить вход командой `claude` в терминале, либо сменить работника |
| Grok CLI | `grok login` в терминале — тот же `grok`, что и в PowerShell |
| Docker | Запустить Docker Desktop. Проверки идут внутри него |
| Ollama | `ollama serve`, затем `ollama pull qwen2.5-coder:14b` |
| Live execution locked | Settings → General → Live coding execution → включить |

## Docker не запущен

Код блокировки `docker_engine`. Проверки качества выполняются в контейнерах, и без
запущенного движка их негде запустить. Запустите Docker Desktop и дождитесь, пока он
скажет, что готов, — приложение, которое ещё стартует, отвечает так же, как остановленное.

## Учётные данные работника не приняты

Код блокировки `coding_cli_credentials`. Наличие файла с учётными данными и их
работоспособность — разные вещи. Проверка перед стартом задаёт провайдеру реальный
вопрос, поэтому истёкший токен ловится за секунды до начала работы, а не через восемь
минут после.

Выполните вход в CLI выбранного работника заново, затем Refresh readiness.

## Grok CLI не найден или вход не выполнен

Код блокировки `grok_cli`. Появляется только если выбран именно этот работник. Либо
`grok login`, либо смените работника в выпадающем списке.

## Прогон упал. Что означает класс причины

У каждого падения есть класс. Он говорит, куда смотреть, и он важнее самого текста ошибки.

- **provider** — сторона провайдера. Истёкший токен, лимит сессии, недоступный CLI.
  О качестве вашего заказа и о сгенерированном коде не говорит ничего. Дождитесь сброса
  лимита и повторите, либо смените работника.
- **budget** — не хватило времени, а не умения. Вызов упёрся в собственные часы.
- **environment** — машина, на которой идёт сборка. Docker, версия Node, место на диске.
- **generated_code** — проверка так и не закрылась после ремонтов. Это единственный класс,
  который действительно говорит о качестве сборки.
- **product_bug** — ошибка самой Studio.
- **unknown** — причина не опознана. Неверный класс хуже отсутствующего, поэтому неизвестное
  не подгоняется под ближайшее.

## Повторить прогон

На экране результата есть **Retry this workspace**. Он переиспользует ту же папку и не
переспрашивает уточнение, бриф и превью дизайна.

**Не создавайте новый заказ из-за падения.** Особенно если прогон умер за несколько секунд
с баннером про лимиты провайдера: это класс `provider`, ждать сброса и нажать Retry дешевле
и быстрее, чем проходить весь путь заново.

Устаревшая строка про лимит сессии одного работника не является блокировкой другого. Если
выбранный работник действительно исчерпан, смените его.
